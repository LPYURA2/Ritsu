# Поставка первого этапа

Дата проверки: **2026-11-10**.

## Результат

Создан отдельный Android-проект: Kotlin, Jetpack Compose, навигация по шести экранам, авторский временный 2D-аватар с длинными волосами, демонстрационный диалог, цели, полномочия, журнал и диагностика.

Рабочее ядро Рицу не подключено и не изменялось. Каталог `~/ritsu-bot/ritsu_termux_kit`, Telegram-бот, базы памяти и рабочие конфигурации не используются. Подготовленные ответы демонстрации не создают вторую модель или независимую личность Рицу.

## Выполненная проверка

Успешно выполнены задачи:

```bash
./gradlew :core:test :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
```

| Проверка | Результат |
| --- | --- |
| JVM-тесты `core` | 18 тестов, 0 ошибок, 0 падений, 0 пропусков |
| Android debug APK | Собран |
| Android test APK | Собран; исходники 8 инструментальных тестов скомпилированы |
| Android Lint | 0 ошибок, 8 предупреждений `GradleDependency` о доступных обновлениях зависимостей |

**Выполнение Android-тестов:** восемь инструментальных тестов скомпилированы, но не выполнены. В этой среде нет `/dev/kvm`; для проверки запущен программный эмулятор Android API 30 x86_64. Его первый запуск не завершился устойчиво: установка приложения вернула `cmd: Failure calling service package: Broken pipe (32)`, после чего перезапустились `zygote` и `system_server`. Системный DropBox подтвердил watchdog: главный поток ожидал `RoleManagerService.maybeGrantDefaultRolesSync` при начальной настройке Android. Первопричина ожидания не установлена. Приложение не было запущено. Это препятствие тестовой платформы до старта приложения; работоспособность интерфейса на устройстве пока не подтверждена. Эмулятор штатно остановлен. Для проверки на устройстве или исправном эмуляторе выполните `./gradlew :app:connectedDebugAndroidTest` и ручную приёмку из README.

## Файлы поставки

- `artifacts/ritsu-demo-debug.apk` — приложение для установки.
- `artifacts/ritsu-demo-tests.apk` — инструментальный test APK; устанавливается вместе с приложением для запуска Android-тестов.
- `artifacts/core-tests.xml` — фактический результат 18 JVM-тестов.
- `artifacts/lint-results.txt` — фактический результат Android Lint.
- `artifacts/emulator-status.txt` — результат попытки запуска тестовой платформы.
- `/workspace/ritsu-android-source.zip` — архив исходников и небольших отчётов проверок; из него исключены кэши, `local.properties`, каталоги `build`, APK и ключи подписи.

Инструкции для самостоятельной сборки и ручной проверки находятся в [README](../README.md). Ограничение сохранения STOP при ошибке записи описано в [SECURITY](SECURITY.md). Подключение единственного существующего ядра и последующие этапы интеграции остаются отдельной согласуемой работой.
