# Файлы для скачивания

- `ritsu-demo-debug.apk` — отладочная демо-сборка Android 11+.
- `ritsu-android.zip` — APK и Android-исходники одним архивом.
- `ritsu-android-source.zip` — только исходники проекта с тестами и инструкциями.
- `SHA256SUMS.txt` — контрольные суммы всех трёх файлов.

На странице файла нажмите **Download raw file**, либо используйте прямые ссылки в README репозитория и описании релиза.

Это демонстрационный клиент. Рабочее ядро Рицу, Telegram и память не подключены. 18 JVM-тестов прошли; UI-тесты собраны, но не выполнены из-за сбоя эмулятора до запуска приложения. Подробнее: `docs/DELIVERY.md`.
